# Cloudflare 永続キャッシュ + 定時/明示同期化

GitHub API のレート制限 (REST 5000 req/h) に達しやすい問題を解消するため、R2 を Vault の実体として読み書きし、読み取りは R2 から返す (ミス時のみ GitHub から取得して書き戻す遅延キャッシュ)、書き込みは R2 先行、GitHub リモートへの同期は Cron (1 時間おき) と明示ボタンのみで行う方式を採用する。これは「サーバー側ストレージを使わない」(ADR-0002) を覆す決定であり、Pages から Workers (Cron Triggers 対応) への移行を伴う。
