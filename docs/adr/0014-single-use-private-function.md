# 単一参照プライベート関数の禁止

呼び出し1回のプライベート関数を別関数に切り出すと定義へのジャンプが必要になり処理の流れが追えないため、インライン化を原則とする。対象は `export` されていないモジュール内関数（トップレベル/ネスト問わず、`function foo()` / `const foo = () =>`）のうち同一スコープ内で参照が1回のみのものとし、再帰の自己参照はカウントから除外、Reactコンポーネント（PascalCase）および hooks（`use*`）はネストでも抽出が慣習的に可読性に寄与するため除外する。検出は `typescript-eslint` のスコープ解析を用いた eslint カスタムルール `local/no-single-use-private-function`（`tools/eslint-plugin-local/index.js`、全スコープを再帰走査）で `error` とし、`src/**/*.{ts,tsx}` のみ対象（`*.test.*`, `features/**` は除外）、真に必要な場合のみ `// eslint-disable-next-line local/no-single-use-private-function -- 理由:` で理由必須の例外を許可する。`--fix` は文脈判断が必要なため提供しない。インライン化で関数が肥大化するため `max-lines-per-function` を `80 → 180` に緩和し、`max-depth` を `4 → 6` に緩和、`no-underscore-dangle` / `unicorn/consistent-function-scoping` は誤検出のため `off` とする。既存約175件（トップレベル167件 + ネスト8件）は本対応で一括インライン化し `pnpm lint` で0を達成、代替案として `knip` / `sonarjs` 流用（目的外）、`oxlint` plugin（参照カウント不可）、`warn` 導入（放置リスク）を検討したが却下した。
